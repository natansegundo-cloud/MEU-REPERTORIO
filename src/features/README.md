# Funcionalidades

Cada subpasta representa um domínio da aplicação:

- `library`: lista, busca e organização da biblioteca;
- `songs`: visualização e edição de músicas;
- `parser`: importação de cifras;
- `transpose`: transposição e motor musical;
- `repertories`: criação e ordenação de repertórios;
- `show-mode`: experiência de apresentação;
- `favorites`: músicas favoritas;
- `settings`: preferências e configurações.

As pastas estão preparadas, mas ainda vazias. Componentes de UI devem ficar
próximos da funcionalidade que atendem; regras musicais devem permanecer
independentes de React.
