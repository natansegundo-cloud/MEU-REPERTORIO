# Ajustes

A área de Nuvem usa magic link quando as variáveis Vite do Supabase estão
configuradas. Sem elas, o aplicativo permanece local e offline.

A sincronização inclui músicas, repertórios e itens de repertório. Favoritos,
preferências de leitura e posição do modo show são específicos de cada aparelho
e ficam fora desta etapa.
