# Capturas — Etapa 28 (polimento funcional)

As capturas usam o acorde `C7M` para comparar duas variações reais do painel:

- **Com omissão:** a variação 2 omite a quinta e exibe `5ª omitida` de forma
  discreta ao lado do resumo de dedos.
- **Sem omissão:** a variação 3 contém a quinta e não exibe nenhum aviso.

Arquivos:

- `diagrama-quinta-omitida-desktop-claro.png`
- `diagrama-quinta-omitida-desktop-escuro.png`
- `diagrama-quinta-omitida-mobile-claro.png`
- `diagrama-quinta-omitida-mobile-escuro.png`
- `diagrama-sem-omissao-desktop-claro.png`
- `diagrama-sem-omissao-mobile-claro.png`

As capturas mobile também mostram “Opções de leitura” como painel sobreposto,
sem expandir a barra nem cortar o botão de salvar tom.
