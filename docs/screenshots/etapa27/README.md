  temas claro e escuro.

  homologação (`?diagramas=1`) e no overlay real (`?diagramas=1&overlay=...`).
  - `diagramas-claro.png` e `diagramas-escuro.png`: oito acordes de referência
    (`Gm7`, `A7M`, `E7(9)`, `C#m7`, `D7M`, `A#º`, `Bm7`, `C#`) e uma seção com
    todas as variações geradas.
  - `diagramas-mobile-escuro.png`: Pixel 7, tema escuro.
  - `overlay-claro.png` e `overlay-escuro.png`: painel real do overlay.

O ambiente temporário de homologação foi removido do código ao final da etapa;
as capturas permanecem apenas como registro visual.
